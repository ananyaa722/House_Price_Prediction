House Price Prediction

Machine Learning Internship Task 2 – Prodigy InfoTech

Project Overview

This project focuses on predicting house prices using Python and Machine Learning techniques. The model learns from housing data to estimate house prices based on the available features.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Workflow

1. Load and explore the dataset.
2. Perform data preprocessing.
3. Analyze the data using visualizations.
4. Train a machine learning regression model.
5. Evaluate the model's performance.
6. Predict house prices.

Files

- "House_price_prediction (1).ipynb" – Jupyter Notebook containing the project code.

How to Run

Open the notebook in Google Colab or Jupyter Notebook and run the cells in sequence.
